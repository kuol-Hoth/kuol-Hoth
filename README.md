# Tap Kuol — Personal website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Make it yours

- Update the introduction, About section, and contact copy in `index.html`.
- Update the Experience & education entries in the Work section as your experience changes.
- Add project cards there when you want to showcase projects.
- Add your email or social links in the Contact section.
- Replace the images in `images/` to update the profile, campus, and community event photos.
- Adjust colors, typography, and layout in `styles.css`.

The site can be deployed to any static host, including GitHub Pages.
